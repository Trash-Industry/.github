# Contribuer à Trash Industry

Les dépôts partagent un socle commun décrit dans [les standards de l'organisation](https://github.com/Trash-Industry/trash-industry/blob/main/docs/standards-communs.md) (document interne).

- Créer une branche par changement et proposer une pull request.
- Une PR traite un objectif à la fois.
- Adapter les tests au risque réel ; expliquer les vérifications non exécutées.
- Ne jamais publier de secrets ou de données personnelles.
- Les findings automatiques sont évalués, pas appliqués aveuglément.
- Ne pas pousser directement sur `main`.
- Les instructions locales du projet détaillent les commandes et l'architecture ; elles ne peuvent pas affaiblir le socle commun sans dérogation documentée.

Les politiques communes sont élaborées dans Trash Lab et adaptées aux besoins réels de chaque projet.
